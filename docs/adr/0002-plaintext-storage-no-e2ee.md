# ADR-0002：明文存储，不做端到端加密

- 状态：已接受
- 日期：2026-08-07

## 背景

日记是最私密的个人数据。数据同时存在手机本地与用户自托管服务器上。

## 决策

数据以明文存储在客户端 SQLite 与服务器 SQLite/文件系统中，不做端到端加密（E2EE）。访问保护依赖：传输层 HTTPS、API Token 认证、服务器的可信边界。

## 后果

- 优点：实现简单；全文搜索、增量同步、换机恢复均不受加密约束；服务器代码无需管理密钥。
- 缺点：任何能访问服务器磁盘/内存的人都能读取日记明文；服务器被入侵 = 数据泄露。
- 信任模型：服务器管理员即用户本人；用户接受该威胁模型。

## 备选方案

- **端到端加密**：客户端用密码派生密钥加密后再上传。代价：密钥管理、换机恢复需密钥协商、服务端全文搜索不可行。此决策一旦推翻，涉及客户端存储、同步协议、服务器架构全部重做。
- **服务器盘加密（LUKS）**：可作运维层补充保险，不改变应用设计；未纳入本决策范围。
