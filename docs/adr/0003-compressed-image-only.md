# ADR-0003：图片压缩版为唯一版本

- 状态：已接受
- 日期：2026-08-07

## 背景

日记条目图片需要从手机传输到服务器并长期保存。手机照片原始文件通常数 MB，直接传输与存储成本过高。

## 决策

客户端在保存/上传前将图片压缩至最长边约 2000px、JPEG 质量约 85%，并生成缩略图用于列表展示。**压缩版是唯一版本：原始照片不保留、不备份、不可恢复。**

## 后果

- 优点：同步快、服务器空间小、列表加载流畅；压缩质量对手机观看场景无损感知。
- 缺点：原始照片永久丢失；未来若需导出摄影级原图不可行。
- 明确不做：原图保留开关、原图双份存储。

## 备选方案

- **原图直传**：空间与带宽成本高，观看价值无增益。
- **压缩版 + 原图开关**：曾考虑；用户确认压缩版足够，不需要额外复杂性与双份存储。
